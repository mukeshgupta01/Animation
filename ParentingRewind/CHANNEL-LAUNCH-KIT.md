# Parenting Rewind channel launch kit

## Identity

- Channel name: **Parenting Rewind**
- Preferred handle: **@ParentingRewind**
- Handle alternatives: **@TheParentingRewind**, **@ParentingRewindTips**
- Tagline: **Pause. Rewind. Repair.**
- Audience: parents and adult caregivers
- Positioning: short, practical, evidence-informed guidance for handling familiar parenting moments with calmer, clearer responses

## Ready-to-paste channel description

Parenting moments don’t always go to plan. Parenting Rewind helps parents and caregivers pause, revisit everyday challenges, and try a calmer, clearer response next time.

You’ll find short, practical videos about boundaries, routines, screen-time transitions, sibling conflict, bedtime, homework, chores, big feelings and everyday family communication. Each episode rewinds a familiar moment, shows what may be escalating it, and offers one specific phrase or action to try instead.

Pause. Rewind. Repair.

This channel provides general parenting education, not personalised therapy, diagnosis or medical advice. Every child and family is different.

## Browser setup checklist

1. Open YouTube Studio and select **Customization** → **Profile**.
2. Confirm the channel name and chosen handle.
3. Upload the profile picture and 2560 x 1440 banner from `branding/`.
4. Paste the channel description and click **Publish**.
5. Add only intentional public links and a suitable business-contact address.
6. Under **Settings** → **Channel**, set audience to **not made for kids** and add the channel keywords.
7. Under **Upload defaults**, set visibility to **Private**, category to **Education**, language to **English**, and configure comment moderation.
8. Complete **Feature eligibility** checks.
9. Create the playlists above.
10. Add Home-tab sections after videos are uploaded.
11. Copy the channel URL or immutable channel ID for isolated OAuth verification before any automated upload is configured.

## Upload safety status

Channel creation does not authorize uploads. Before automation, create a separate Parenting Rewind OAuth token, verify its exact immutable channel ID, save a channel lock, and obtain explicit approval for a private test upload. Never reuse Birthday Songs or Tiny Tales credentials, ledgers, archives or Scheduled Tasks.
