# Pip and the Missing Picnic Basket

A 52-second AI-puppet preschool mystery. Pip asks children to follow two clues,
discovers Bunny's surprise picnic, and closes with a gentle message about asking
permission and sharing.

Render the complete 1280×720 video:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\render.ps1
```

The final video is written to
`output/pip-and-the-missing-picnic-basket.mp4`.
