# Pip and the Missing Picnic Basket

A 52-second AI-assisted preschool mystery. Pip's picnic basket disappears, so he
invites children to follow footprints and count crumbs before Bunny reveals a
surprise picnic. The ending models asking permission, apologising and sharing.

## Render the puppet version

```powershell
cd .\alternate-tool
powershell -NoProfile -ExecutionPolicy Bypass -File .\render.ps1
```

The 1280×720 final is written to
`alternate-tool/output/pip-and-the-missing-picnic-basket.mp4`.

The earlier procedural Blender experiment remains in this folder for comparison,
but the AI-puppet version is the selected visual direction.
