# Baa Baa Black Sheep video renderer

Windows 11 project for a 70-second, 1920x1080, 24 fps illustrated nursery-rhyme video.

## Build

```powershell
cd C:\Animation\Animation\KidsRhymes
powershell -NoProfile -ExecutionPolicy Bypass -File .\render.ps1
```

The renderer creates an acoustic nursery-rhyme arrangement through MuseScore, mixes a score-driven English singing vocal generated with Sinsy, and applies slow Ken Burns motion and dissolves to six illustrated scenes. The sheep painted into each scene stays static. It encodes H.264/AAC with FFmpeg and writes an FFprobe report.

Sung output: `C:\Animation\Animation\KidsRhymes\output\baa-baa-black-sheep\baa-baa-black-sheep-sung.mp4`

The default renderer also creates the upload-ready branded version:

`C:\KidsRhymes\output\baa-baa-black-sheep\baa-baa-black-sheep-with-tiny-tales-intro.mp4`

The lyrics are public domain. The arrangement and scene artwork created for this project are original. The singing voice was synthesized with **Sinsy**; retain this attribution when publishing or distributing the video.

## Tiny Tales channel branding

Render the five-second bunny ident, prepend it to the rhyme, and size the YouTube banner:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\KidsRhymes\render-intro.ps1
```

The five-second `Tiny Tales` ident is the project default for all future rhymes. To brand any new rendered video, use:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\KidsRhymes\add-tiny-tales-intro.ps1 -InputVideo C:\path\to\rhyme.mp4
```

## Final Baa Baa mix

The improved mix uses MuseScore's acoustic instrument library and adds the square Tiny Tales watermark:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\KidsRhymes\generate-better-music.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\KidsRhymes\finish-baa-baa.ps1
```

The vocal score is generated by `generate-sinsy-score.py` and stored as
`output\baa-baa-black-sheep\audio\baa-baa-black-sheep-sinsy.musicxml`.

`generate-playful-music.ps1` creates the alternative child-focused “bounce and sparkle”
arrangement and a short MP3 audition before it is placed into the final video.
